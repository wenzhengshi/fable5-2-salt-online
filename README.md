# 盐线行动 · Saltline

一款运行在浏览器中的多人在线 3D 港口枪战游戏。所有进入战场的玩家互为敌人，被击倒后等待 5 秒即可重新加入对战。

项目基于 Node.js、Express、WebSocket 与 Three.js 构建，无需数据库。排行榜保存在本地 `data/` 目录中。

## v1.26.7 专注结束立即恢复战场

专注模式结束后不再停留在观战镜头：即使从暂停菜单开启专注，倒计时结束也会自动继续行动，HUD、输入、玩家控制与第一人称镜头一起恢复；服务端复活消息延迟到达时也会在客户端补上部署，无需刷新页面。

## v1.26.6 专注观战可切换玩家

专注模式现在支持手动选择观战目标：可通过上一位 / 下一位按钮、在线玩家列表或键盘 `←` / `→` 切换，手动锁定后保持视角；目标离开或阵亡时自动回退到轮播，也可随时恢复自动轮播。切换只读取现有实时快照，不改变服务端只读锁定。

## v1.26.5 专注观战全服可见

玩家开启手动或自动专注模式后，服务端会向公屏广播系统播报，战场名单同步显示“专注”徽章。在线玩家接口与实时快照都会返回 `focused` 和 `focus` 详情，其他玩家可以直接看出谁正在观战；专注结束返回战场时也会播报。系统消息写入大字历史，并按玩家当前语言显示。

## v1.26.4 复活不打断聊天输入

玩家在死亡倒计时或复活瞬间正在输入全服大字时，聊天面板、已输入文字与光标位置都会保持不变，复活流程不再请求鼠标锁定，也不会让画布抢走输入焦点。关闭聊天后仍按原有方式点击画面恢复视角锁定。

## v1.26.3 路牌防滥用

路牌创建由服务端执行多层限流：同一玩家每日最多 10 块，短时间内连续放置会受到冷却和突发上限约束；轮换 Cookie 时，服务端还会结合浏览器身份与网络来源继续限制。单张地图、细网格和周边区域同样设有容量与密度上限，避免程序批量铺牌占满道路、地标或传送门周边。成功立牌后会显示今日剩余额度。

## v1.26.2 传送门更近、带方位指引

青云宗三座传送门从远处地标移回入口周边：湾城与西部荒原分别位于入口东西两侧草坡，霓虹雨城位于正前方石阶平台，距落点都只有约 31–32 米。三座门仍朝向不同方向，不会挤在一起。进入青云宗后，左侧会显示三张地图的实时距离与指向箭头，支持中英文，方便直接找到对应门环。

## v1.25.9 自定义提示弹窗

回放相关的录制提醒与删除确认改用项目内的暗色战术风格模态框，不再弹出浏览器原生 `confirm`。新弹窗支持中英文按钮、焦点管理与键盘操作，桌面端居中展示，手机端自动切换为底部抽屉；删除回放时会显示文件名并保留二次确认。

## v1.25.8 微信内置浏览器录制提醒

本地回放会自动识别微信内置浏览器。在微信中打开回放面板时，会明确提示先通过右上角「···」选择「在浏览器打开」，再开始录制；点击录制还会二次确认。微信内点击下载会被直接拦截并引导切换浏览器，避免录制完成后才发现无法下载。提示与确认文案均支持中英文。

## v1.25.7 服务端约束旧客户端

服务端现在直接约束无人机空气墙、弹夹容量、空弹换弹和命中次数。未刷新缓存的旧客户端即使继续发送墙外坐标、无限连发或重复命中包，也会被服务器拉回墙内、强制在 30 发后换弹，并且每发确认射击只能兑现一次伤害。

## v1.25.6 空气墙、打字可见与空中切换复活

无人机恢复旧版 `x=-40…40、z=-30…30` 空气墙，无法飞出港口边界；聊天打字导致游戏暂停时仍保持在线可见。无人机在空中切换操作单位后，选择会立即保存并在随机地面点位复活，不再从原高度直接掉落。无限弹药现在只提供无限备弹，弹夹打空后仍需等待完整换弹。

## v1.25.5 飞行单位完整防穿模

无人机与飞行单位现在按真实碰撞盒做三维位置修正：横向移动会被船壳、集装箱和建筑阻挡，升降时也会被屋顶、船楼底面与甲板表面拦截。大型货船 `KITTIWAKE` 的船壳、上层建筑和艉部结构全部纳入碰撞，并根据可视模型子对象动态生成整船飞行包络，补上船首、船尾与高处桅杆等区域，避免镜头或机体进入模型内部。

## v1.25.3 安卓应用市场入口

游戏标题页与暂停菜单新增“安卓应用市场”入口，点击后在新标签页打开盐线行动应用市场下载页。入口支持中英文界面，并沿用现有深色战术风格。手机端同步收紧标题、说明、状态和信息文本字号，所有按钮的尺寸与位置保持不变。静态资源版本同步更新，避免浏览器继续使用旧缓存。

## v1.25.2 本地回放录制游戏音效

本地回放现在同时录制战场画面和游戏音效。新增的 WebAudio 分流层会从游戏主输出复制一份音轨给本机 `MediaRecorder`，枪声、爆炸、载具和背景音乐都会进入回放文件；停止录制不会影响游戏继续发声。音轨优先封装为 MP4/AAC，不支持时自动回退到 WebM/Opus。录像仍只保存在当前浏览器的 IndexedDB，不上传服务器，也不调用麦克风。

## v1.25.1 正式版整理

本版以当前工作区的 `v1.25.0` 为代码基线，并逐文件核对上传的 `v1.24.5` 源码包：上传包内 83 个文件均存在，其中核心游戏资源与当前版本完全一致，其余差异均为后续新增功能与托管修复，因此不回退旧包。版本号现在只维护在 `package.json`，游戏元信息接口与静态资源缓存号会自动同步。

发布前可执行 `npm run release:check`，检查必需文件、CommonJS、Node.js 18+ 启动方式、依赖白名单、双语文案、`PORT` / `HOST` 监听、API 文档及 `data/` 运行数据残留。

## v1.25.0 多人撤离船与外海交战区

撤离船不再绑定任务完成状态。玩家可以在任意时刻靠近撤离点的船，按 `E` 接管舵位或进入乘客位；同一艘船的坐标、朝向、速度和四个座位由服务端同步。舵手可以向全服发送集合邀请，乘客可保留第一人称瞄准与射击能力。

撤离点原有的客户端硬边界已经扩展，海面新增“外海交战区”平台，包含碰撞地面、掩体、登船落点和独立复活点。玩家可以驾船离开港口、在平台下船并对战；在外海死亡后会优先在外海平台复活。船只无人使用一段时间，或全服最后一名玩家离线时，会自动回到撤离码头。

## v1.24.5 渲染策略回退

撤回 v1.24.3 对 WebGL 渲染偏好的调整，恢复原有渲染器与画质探测逻辑：主渲染器、单位预览与死亡回放继续优先请求 `high-performance`，浏览器上下文预热与失败回退保持原样。

## v1.24.4 本地回放重复下载修复

本地回放下载原先同时使用原生 `<a download>` 与点击处理器内的程序化下载，单次点击会触发两次下载，浏览器随后把后续点击当作批量自动下载拦截。v1.24.4 改为单一按钮式下载路径，每次点击生成独立的 Blob URL，并在释放前保留足够时间，同一段录像可以反复下载。

## v1.24.1 远端机器狗真实模型修复

远端玩家操控的机器狗与无人机现在会稳定复用游戏内的骨骼单位模型；即使首个联网快照早于模型模块加载，也会持续等待并自动替换临时兜底，不再出现永久方块狗。

## v1.24.0 服务端权威死亡回放

死亡回放不再由浏览器用本地快照自行拼接。服务端以 10 Hz 记录双方的权威位置、朝向与俯仰，并记录真实射击的枪口位置、弹道方向和命中伤害；击杀发生时截取此前 4.5 秒的完整时间线，随 `youDied.replay` 下发给被击杀者。Three.js 只负责把这份服务端实录重建为三维追踪镜头，双方移动、枪火时刻与命中倒地均来自实际对战数据。游戏继续仅使用 WebGL2 + Three.js 三维渲染。

## 功能

- 多人在线自由混战（free-for-all）
- 5 秒自动复活与 2 秒复活保护
- 服务端命中校验、生命值、击杀与战绩统计
- 实时玩家位置、射击表现和击杀信息
- 服务端权威死亡回放：10 Hz 记录双方真实轨迹、枪口弹道与命中事件，客户端不再本地伪造
- 公屏击杀通知与个人死亡卡片显示击杀者操控单位（男/女士兵、机器狗、无人机）
- 任务未完成也可驾驶撤离船，支持舵手和三名乘客实时同船
- 船上可瞄准、射击，支持全服集合邀请、座位状态和死亡自动离船
- 撤离点空气墙替换为开放海面与“外海交战区”平台，支持外海步战和对应复活点
- 在线人数、战场名单与排行榜
- 服务端 PCM 在线语音中继，支持全服收听、单独静音与 `M` 键开麦 / 关麦
- 全服大字广播与快捷喊话，支持 `T` 键打开和历史记录分页
- 玩家代号、聊天与历史排行榜内容安全过滤
- 支持对简体/繁体、拆字、全角、零宽字符、符号替代和常见同形字规避的识别
- 设置内提供手动专注模式：服务端强制只读 30 分钟，期间只能自动跟随观战实时战局
- 连续实际战斗满 4 小时自动强制专注 20 分钟，期间同样只能观战，计时与锁定均由服务端执行
- 专注记录持久化本机标识、浏览器指纹与 IP，刷新或重连后锁定仍然生效
- 支持男女士兵、机器狗和无人机四类操控单位
- 机器狗复用港口猎犬模型，无人机复用港口海鸥无人机模型，均拥有完整开火、语音、通讯、受击与复活权限
- 无人机按 `Space` 上升、`Shift` 下降，可在空中侦察和交战
- 仅使用 WebGL2 + Three.js 三维渲染，不再提供 Canvas 2D 战术模式；画质提供极低、低、中、高、极高五档，低配手机可关闭阴影、泛光、反射与体积光
- 中英文界面切换
- 桌面端与移动端响应式布局

## 环境要求

- Node.js 18 或更高版本
- npm 9 或更高版本
- 支持 WebSocket 与 WebGL2 的现代浏览器；WebGL2 不可用时不会进入游戏
- 在线语音需要 HTTPS 或 `localhost` 环境，并授予麦克风权限

## 本地运行

```bash
npm install
cp .env.example .env
npm start
```

Windows PowerShell 可使用：

```powershell
Copy-Item .env.example .env
npm start
```

浏览器访问 `http://localhost:3000`。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | HTTP 与 WebSocket 共用端口 |
| `HOST` | 代码回退为 `127.0.0.1` | 监听地址；`.env.example` 使用 `0.0.0.0`，便于本地和容器访问 |
| `JICREATE_DATA_DIR` | 未设置 | 托管平台提供的持久化数据目录，优先级最高 |
| `DATA_DIR` | 未设置 | 自定义持久化数据目录；未设置时回退到项目内 `data/` |

`.env` 仅用于本地配置，不会提交到 Git。公开部署时请在平台的环境变量设置中配置实际值。

### 玩家路牌

路牌只能在青云宗或湾城、西部荒原、霓虹雨城等远征地图内使用，并且需要保持多人连接。

- 瞄准 5 米内的平坦地面后按 `B`，输入最多 32 个字符并选择蓝底白字或黄底黑字，即可在绿色落点标记处立牌。
- 路牌会持续保存在服务器中，并显示提交时间（北京时间，精确到秒）；同一位置附近已有路牌时需要换一个地点。
- 同一玩家每天最多立 10 块。服务端还限制短时间内的连续放置；轮换 Cookie 不会解除浏览器身份、网络来源和地图密度的限制。
- 传送门、地图落点和回程落点周围 10 米内不能立牌。
- 靠近自己的路牌后按 `Delete` 可以拔除。为了保留公共记录，自己的路牌最早只能在次日北京时间零点后拔除；其他玩家不能拔除你的路牌。
- 移动端和触控设备可使用地图内的“立路牌”“拔路牌”按钮。管理员可在 `/admin/signs` 审核或标记违规牌面。

## 数据持久化

排行榜写入 `data/leaderboard.json`，全服大字历史追加写入 `data/chat-history.jsonl`，专注记录写入 `data/focus-records.json`，连续游玩计时写入 `data/play-sessions.json`。系统会优先使用 `JICREATE_DATA_DIR`，其次使用 `DATA_DIR`，均未设置时回退到项目内 `data/`。项目内 `data/` 使用 `2777` 目录权限、数据文件使用 `0664` 权限，确保临时托管在下一轮还原时可被平台服务账号安全清理；外部持久化目录不强制改权。写盘暂时失败时，大字仍会正常广播，并进入自动重试队列；连续游玩计时和强制专注也会先在内存生效。`data/` 下的运行数据默认不进入 Git；容器部署若需要跨重启保留数据，请挂载持久化目录。

## 港口地图传送门

从港口的时空隧道进入青云宗后，湾城（Bayhaven）、西部荒原（Dustfall）与霓虹雨城（Mothlight）三座传送门位于入口东西两侧草坡与正前方石阶平台，距落点约 31–32 米，既不会堵在门口，也不用跑遍全岛寻找。页面左侧会显示三座门的实时距离与指向箭头。返回青云宗时会出现在对应门户旁；青云宗另设回港门。多人对局中，同一张地图内的玩家彼此可见。新增两艘停泊船作为港口场景摆设，原有撤离艇继续提供驾驶与联机乘坐。

新增地图使用上传版本的地图生成器和环境资源。Dustfall 植被模型来自 Quaternius，地表贴图来自 Poly Haven，均使用原版注明的 CC0 资源。Bayhaven 随附原版许可。

进入湾城、西部荒原和霓虹雨城后，背景音乐会自动切换。湾城使用原版 Tideline 98 电台曲《Low Sun, High Tide》，西部荒原与霓虹雨城使用各原版程序化音乐的独立渲染。青云宗和港口沿用现有配乐。

## 管理后台与全服备份

访问同站点的 `/admin`，首次登录使用账号 `admin`、初始密码 `abc123456@`。登录后按提示设置至少 12 个字符的新密码，再重新登录下载备份。后续可在后台点「修改管理员密码」。新密码的哈希保存在服务器数据目录的 `.admin-credentials.json` 中。请在对外开放站点前完成首次改密。

ZIP 内的 `data/` 保留存储目录的文件结构，包含路牌、排行榜、聊天、专注与游玩时长等持久化数据。`manifest.json` 记录备份时间、游戏版本和文件清单。配置文件、锁文件、临时文件和浏览器本地数据不在包里。服务器可在备份期间继续运行，各文件按读取时的状态收集。

如需恢复，先停止游戏服务，将现有数据目录移到安全位置留作备份。将 ZIP 内 `data/` 的内容解压到新的空数据目录，再重启。默认数据目录为项目的 `data/`，也可由 `JICREATE_DATA_DIR` 或 `DATA_DIR` 指定。

恢复时请把原数据目录中的 `.admin-credentials.json` 一并移到新目录，以保留管理员密码。该文件不包含在下载的备份 ZIP 中。

在 `/admin/signs` 可以查看和审核各地图的路牌。正常提交的路牌直接显示。标记违规后，玩家端只会收到替换文字「该牌子违规」，路牌位置和归属照旧。原文可供管理员在后台查看。
